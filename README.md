# 新词新站点点通（page-helper）

插件名用户 10-12 定；图标是雷达环 + 新信号点（`design/icon/`：gpt-image-2.5 出 3 个方案，美术顾问选 ring-dot，去掉白色方底、16px 去红点放大橙点，`build.py` 生成 `extension/icons/`）。

Chrome 侧边栏插件，配一个本机小服务。**只在 sim.3ue.co 上采集数据**（用户 10-12 定）：manifest 的站点权限只有 `https://sim.3ue.co/*`、`https://new.web.cafe/*`（找词的数据源）和本机服务地址，别的网站插件连网址都读不到；当前标签页不是 sim 时，「域名注册时间」「新进热词」只显示「只在 sim.3ue.co 上用」，「找词」「找站」不看当前标签页。点工具栏图标打开侧边栏，顶部四个页签只切换视图（打开时按当前页面默认选一个：sim 关键词表 → 新进热词，sim 其他页 → 域名注册时间，不在 sim → 找词），每个视图有自己的主按钮。

界面设计稿：claude.ai 画布「浏览助手侧边栏设计」https://claude.ai/artifact/GJWmb27QEkMjvDMFzNQii9 。**样式用方向 A**（用户 10-12 看过实物后选的：一行一个词、Trends 胶囊跟在词后面、28 天 / 平均各一列、圆角状态卡片）；A2 那一行的功能（和上次比、各种结束状态）保留，样式按 A 画。画布上的数字是示意（稿里还写着 500，现在是 100）。

- **域名注册时间**：收集当前页所有域名（链接地址 + 正文里像域名的文字），**忽略本站**（3ue.co，用户 10-12 定），按注册日从新到旧排列；1 年内注册的域龄是蓝色实底胶囊、1–2 年浅蓝，60 天内按天显示（「38 天」）；注册日的来源（RDAP / whois）在注册日的悬停提示里。
- **新进热词**：在 sim.3ue.co 的关键词表里，**按页面当前的排序**从第 1 页自动翻页，收集前 100 条（用户 10-12 由 500 改成 100）KD=0（表里显示「-」）且「28 天流量 ÷ 平均体量」> 5 的词；> 20 为红档（红实底倍数），> 5 为橙档（橙浅底倍数）。表里同时标橙框 / 红框，翻页、排序后自动重标。一轮最多翻 50 页，不够 100 条就停下给「再翻 50 页」；可以「停止」「继续收集」；收完回到你原来在的那一页。**名次 = 收集后的顺序**（1、2、3…，用户 10-12 定）；词在 sim 表里的位置放在关键词的悬停提示和 CSV 的「表内名次」列。每行数字下面是**热门网址的站**（去掉 www.，用户 10-12 同意资深用户的建议：这个词的流量是大站在吃还是新站在吃），悬停看完整网址，点开是那个站的新进关键词页。
- **找词**：从 web.cafe 新词发现服务（new.web.cafe/keywords，用你在 Chrome 里的登录）拉「长期大词」整页（602）和「二次爆火」（389），两组都有的算一个，按方向（AI / 工具 / 游戏 / 其它）和分组筛、搜词；按 GPTs 倍数排；点词打开 sim 的 SERP 市场参与者页，后面照样有 Trends。缓存 12 小时。侧边栏直接请求拿不到时，借一个 web.cafe 标签页在页面里请求（没有就后台开一个，用完关掉）。
- **找站**（10-12 加）：sim 上 checkout.stripe.com 的「外链 → 引荐网站」表（近 28 天、全球、全部流量），约 970 个站——能把访客送进 Stripe 结账页的站，就是在收钱的站。显示名次、域名、域龄、行业、全球排名、流量份额；搜域名或行业、按行业筛；点域名打开它的新进关键词页，后面的图标打开网站本身；忽略 3ue.co / similarweb.com。
  - **域龄 + 「1 年内注册」筛选 + 复制**（用户 10-12 同意资深用户的建议，为了从在收钱的站里找新站）：主机名先归到可注册域名（`app.mailerfind.com` → `mailerfind.com`，托管子域标「托管」不查），复用本机服务查注册日——先一次 20 个拿本机已经查过的（`/lookup` 的 `cachedOnly`，不联网，秒出），再 6 路并发查没查过的，查到一批就地换上胶囊（不重画整张表）。「1 年内注册 N」能和「首次出现」、行业、搜索叠着用。「复制 N 个」复制下面正显示的那些站（按当前筛选），列：名次、域名、变化、行业、全球排名、占 Stripe 引荐、注册日、域龄。
  - **存下来以后满 30 天才自动重拉，其余时间不动它；要刷新就点「重新拉取」**（用户 10-12 定）。满 30 天后每次打开侧边栏最多自动试一次（没登录 sim 时不会反复开标签页）。
  - 和上一份比：上一份没有的标「首次出现」。没满 30 天手动重拉时，对比基线不变（还是原来那一份），30 天的节奏不乱。第一份没有可比的，不标。
  - 怎么读：已经开着这张表就直接读它（读完回第 1 页），没开就在后台开一个、读完关掉。10 页每页 100 个，翻页节奏由侧边栏控制（同新进热词）。sim 翻页时整张表连同页码栏会先拆掉再画，页码框刚画出来时先显示 1、过一会儿才变成真页码——所以页数自己数，每翻一页都等到「页码框显示应在的页、且连着两次读到同一张表」才收这一页（最多等 40 秒，等不到就停下报错、不存，名次会错）；表头写的总数和读到的对不上时，存下但在卡片上注明「只读到 N / 总数 个」。
  - 每次读表都核对页面地址还是这张表（全球 / 28 天 / 全部流量 / 引荐网站页签 / checkout.stripe.com），用户开着的那页中途跳走了就停、不存、不再翻它。
  - 同一时间只跑一轮：双击、反复点页签不会开第二轮；「停止」立刻关掉自己开的标签页（或让用户那页回第 1 页），等这一轮退出后回到存着的那份，停止后不会再写缓存；停止后马上重拉，新的一轮等旧的收拾完才开始，旧的只收拾自己的标签页。
  - 后台开的那页什么时候关：这一轮在侧边栏开着时结束（读完 / 停止 / 出错），而且那页是自己开的、你没切过去看过、没在里面跳到别处、还停在引荐页、当前不在前台，才关；有一条不满足就留着归你。侧边栏中途被关掉时不收拾，后台那页留着，下次拉取直接复用它，不会越积越多（Codex 10-12 第二轮：为「侧边栏关掉也要替你关」加的 service worker 连接、归属记录、启动时清孤儿三层，会误关你在看的页、误删另一个窗口正在用的页，整套去掉了）。
  - 写缓存那一下不能停（几毫秒，按钮显示「正在保存」）；停止时还在等页面加载的，马上退出、不拖住下一轮（注入用 `injectImmediately`，不等 document_idle，每次等待都有期限）。
  - 用户碰没碰过后台那页按标签页记，一直记到那一轮收拾完（停止后马上重拉时，旧一轮还在收拾，碰它也算在旧一轮身上）。缓存过期后手动重拉过（哪怕停了），这一份就不再自动拉。
  - 读不到时（多半没登录 sim）：卡片主按钮「打开引荐页」，那页加载完会自动再读。重新拉取时下面先显示上一份。
  - 存在 `chrome.storage.local`（键 `stripe-ref-v1`），不进本机服务。

### 和上次比

规则来源：产品经理的意见照用（用户 10-12 确认「产品经理正确的意见还是要听的」），只有两处按用户改：
1. 标记只有一种「首次出现」（用户 10-12 定，替代产品经理的「新 / 新达标 / 升红」三档）：每次查询是独立的——只要 KD=0 且倍数 > 5 就是热词，不管以前见没见过，照样收满 100 条；只是**上次查询收到的那份名单（上次的前 100 条）里没有的**，标「首次出现」。默认显示全部，点「首次出现 N」只看这些。
2. 不做「点一行在网页里定位」（产品经理提的风险，用户也明确不要）。

其余规则：
- 每次查完自动存一份快照到本机服务（`var/cache.sqlite` 的 `snapshots` 表，不出本机）。快照存所有扫过的行（含没达标的）。
- **同一张表**：新进热词 = 页面网址（含域名、国家、时间段、品牌/新进筛选）+ 当前排序；域名 = 页面网址去掉 utm 等跟踪参数（sim 这种 `#/` 路由保留 # 后面的部分，# 里的跟踪参数也去掉）。
- **一天一份**：同一张表同一天只留最后一份（替换是一个事务，失败会回滚、旧的那份不丢）；每张表保留最近 30 份。「再翻 50 页」接着收完，会替换当天那份。
- **上次**：默认是「今天之前」最近的一份，当天反复重查不会挤掉上周的；下拉框可以换成更早的。
- **消失** = 上次名单里有、这次实际扫到的表内范围里没达标或不在表里，折叠在列表底部只显示数量（显示上次的名次）；CSV 末尾也附上。
- 第一次查（或只有今天的快照）：提示「已存下来」；同一网址有别的排序的快照时提示「排序不同，不能比」。
- 停止、出错的那一轮不存、不比，也不显示首次出现标记。
- **域名**：和同一页上一次扫描比，上次没有的标「首次出现」，消失的折叠在底部；另有「从没见过」= 在任何页面上都是今天第一次见到（本机服务的 `seen` 表）。头一天用时所有域名都是第一次见、没有意义，所以记录是今天才开始的就不显示。
- 导出 CSV / 复制表格都带「变化」列（首次出现 / 从没见过 / 消失）；CSV 另有「名次」「上次名次」（都是收集顺序）和「表内名次」。

### 为什么翻页由侧边栏驱动

标签页在后台待 5 分钟后，页面里的定时器会被 Chrome 限流到每分钟一次（10-12 实测：后台翻页把「40 秒没加载出来」误判了）。所以页面脚本只提供「读本页 / 下一页 / 跳页」三个动作，判断「新页渲染好了」靠 DOM 变化（MutationObserver），不用定时轮询；翻页间隔、超时、停止都在侧边栏里（侧边栏开着时不限流）。代价：收集过程中关掉侧边栏就会停。

### 侧边栏里的链接

新标签页打开，按住 ⌘ 在后台打开；地区一律 999 全球：

- 点**域名** → 该域名的新进非品牌关键词页 `#/organicsearch/pageAnalysis/website-keyword-v2/*/999/28d?key=<域名>&pageFilter=[{"url":"<域名>","searchType":"domain"}]&…&Change=New`，打开后可以直接收集新进热词。
- 点**热词** → 该词的 SERP 市场参与者页 `#/digitalsuite/acquisition/keyword/organic/search/999/28d/keywordAnalysis_2?keyword=<词>&…`。
- 点热词后面的 **Trends 胶囊按钮** → Google Trends 近 1 个月全球，和基准词 `gpts` 对比（基准写死在 `TRENDS_BASE`，不要改）。地址格式照 Trends 自己的：词先编码一次、整个 q 再编码一次（空格 → `%2520`）。
- 不做「点一行在网页里定位」（紧挨 Trends 容易误点、还会翻动表格；用户 10-12 也明确不要）。

**导出 CSV**：收完（或停止后）点卡片右上角「导出 CSV」。按收集顺序；列：框色、变化、名次、上次名次、表内名次、关键词、KD、28 天流量、平均体量、倍数、倍数是下限、热门网址（取格子里的链接，完整网址）。关键词分析和 Google Trends 链接不进 CSV（用户 10-12 定）。文件带 BOM，Excel 直接打开中文不乱码；关键词、网址以 `= + - @` 开头的前面垫 `'`，防止被当公式。

模板在 `extension/panel.js` 的 `kwUrl` / `domainUrl` / `trendsUrl`；条数、页数上限、翻页间隔在文件开头的 `TARGET` / `PAGE_CAP` / `PAGE_GAP`。

## 安装

1. 本机服务（已装好，开机自启）：`launchd/com.wy.page-helper.plist` 已复制到 `~/Library/LaunchAgents/`，监听 `127.0.0.1:8793`。
   - 重启：`launchctl kickstart -k gui/$(id -u)/com.wy.page-helper`

   - 日志：`var/logs/service.err.log`
2. 插件：Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」→「加载已解压的扩展程序」→ 选 `extension/` 目录。之后把图标固定到工具栏。
   - 改了插件代码后，在 `chrome://extensions` 点该插件的刷新按钮；已打开的网页要刷新一次（旧的注入脚本会失效）。

## 注册日从哪来

顺序：RDAP（IANA 引导表 `data.iana.org/rdap/dns.json`，7 天刷新）→ whois 43 端口（先问 `whois.iana.org` 拿该后缀的 whois 服务器）。

- RDAP 不覆盖 .io / .me / .co / .de / .so / .gg / .sh 等，靠 whois 补；2026-10-12 实测 .io/.me/.co 都能补上。
- **不用 AITDK 兜底**：注册局不公开注册日时（如 .de），AITDK 的「注册日」是最后修改日（spiegel.de 给 2021-07-26 = DENIC `Changed:`），会把老站冒充成新站。.de 如实显示「查不到」。
- 缓存在 `var/cache.sqlite`：查到的永久缓存；查不到的 3 天后重查；超时、限流这类临时错误不缓存。
- 托管子域（`*.vercel.app`、`*.github.io` 等，按公共后缀表私有段判断）单独列出，不查——查到的是平台的注册日，没有参考价值。
- 子域名归并到可注册域名：`tools.aitutorium.com` → `aitutorium.com`，`chromewebstore.google.com` → `google.com`。
- 正文文字里只出现、后缀又像文件扩展名的（`.md` `.py` `.zip` `.mov`）当文件名丢掉；同一域名在链接里出现过就保留。

## 局限

- 只读得到页面上已经渲染出来的内容；分页 / 虚拟滚动的表格要翻到才收得到。
- 新进热词只认表头文字为「关键词」「KD」「28 天流量」「平均体量」的表格（sim.3ue.co 中文界面）；换英文界面或改版要改 `extension/hot.js` 里的表头匹配。
- 「< 50」只知道上限，倍数取下限：分母是「< 50」时显示「≥24.0×」；分子是「< 50」的永远不标（确定不了是否超过阈值）。
- 倍数恰好等于 5 或 20 不升档（规则是严格大于）。KD 只有空、「-」或数值 0 才算 0，「N/A」之类不算。
- 正文文字只认 ASCII 域名（中文正文里域名常紧贴汉字，放开 Unicode 会把「访问ilovepdf.com」整段当域名）；链接里的中文域名浏览器已转成 punycode，照常收。
- 收集过程中关掉侧边栏会停；页面刷新或跳走也会停（已收的保留，可以继续）。
- 关掉收集用的那个 sim 标签页：结果还能看、能导出、链接照样能开（10-12 修：之前新标签页挂在已关闭的标签页后面，Chrome 静默拒绝，点关键词没反应）；只是不能「继续收集」，要在关键词表上点「重新收集」。
- 收集时请别手动翻那张表；排序或筛选被改了会自动停下。

## 代码

用 git 管理（2026-10-12 起，`main` 分支，只在本机，没有远程仓库）。不纳入：`var/`（本机服务的缓存、快照库、日志）和状态帧单张（`node test/frames.cjs` 随时重截）；评审用的总览图和版本对照图留在库里。验收命令：`node test/refs-check.cjs`（找站 10 个场景），界面改动用 `node test/frames.cjs <目录>` 截亮暗两套帧看。

| 文件 | 作用 |
|---|---|
| `extension/panel.js` | 侧边栏：视图切换、收集域名（注入 `collectHosts`）、6 路并发查注册日、驱动翻页收集、快照对比、导出、渲染 |
